# TDdemo：三维针尖扫描演示

参考 `Desktop/demo/afm-ters_v6.py` 的样品导入、扫描路径和有限半径针尖包络思路，采用原生浏览器 Canvas 绘制可旋转的三维投影。无 npm、Python 或网络依赖。

## 运行

双击 `index.html`，使用 Edge 或 Chrome 打开。所有文件须放在同一文件夹。

1. 选择内置表面，或先选坐标单位，再点击“导入 PDB / XYZ”。
2. 导入 `../TERS-DriftLab/gold.pdb` 时使用默认 **Å**。文件由选择框读取，不上传网络，也不写死路径。
3. 调整尖端半径、垂直抬升量、扫描分辨率和路径，点击开始扫描。
4. 拖动三维画面旋转，滚轮缩放。扫描支持暂停、继续和重置。
5. 查看逐点形貌图和当前扫描行剖面，导出 JSON 保存样品、参数和已采样数据。

修改针尖或路径参数会重置扫描。播放速度只影响动画，每点模拟驻留时间固定为 0.02 s；逐行回扫附加 0.1 s，回扫不采样，画面直接移到下一行起点。

## 文件

- `index.html`：界面、样式及操作说明。
- `model.js`：坐标解析、样品表面、扫描路径、球形针尖包络计算。
- `app.js`：三维投影、交互、采样和 JSON 导出。
- `test_model.js`：Node.js 下可运行的数值检查。

## 几何模型与边界

高度场由离散节点构成。针尖最低点的高度计算为：

`z_tip = max(h_j + sqrt(R² - distance_xy²) - R) + g`

仅考虑水平距离不超过 R 的有效节点。g 是在接触包络基础上的**垂直抬升量**，不是最小法向间隙。该模型在离散节点上检查球形尖端的接近约束，不保证插值网格之间的连续碰撞约束，也不模拟杆部碰撞、真实 AFM/STM 反馈或针尖变形。

PDB 按固定列解析坐标，忽略原子序号，因此能读取 gold.pdb 的末尾非十进制序号。原子坐标归一化至原点，按 65×65 网格取最高原子中心形成上包络；空网格保留无效状态。此表面**不是加入原子半径后的真实接触表面**，也不保留悬空结构或原子间化学键。界面展示的是上表面，不是逐个渲染全部原子。

内置样品尺寸为 20×20 nm。表面和针尖均使用 nm，三维投影没有单独夸大 z 轴。球形尖端和杆部是示意渲染，不构成光学模型。

本版完成计划书 Step 1 的原型：不包含拉曼光谱、随机拉曼效率、漂移或深度学习。形貌图记录 `z_tip - g`，它包含有限针尖尺寸的形貌展宽，不能称为真实化学图。
